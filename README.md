# Conecta – frontend

Frontend (HTML, CSS, JavaScript y Bootstrap 5) para el registro y búsqueda de usuarios.
Consume la API REST del backend con **Fetch API (AJAX)**.

Gloria Leticia González Troncoso – 2023670143 – 7CM1 – UPIIZ IPN

## Páginas

- `index.html` – Inicio
- `registro.html` – Registro de usuario
- `busqueda.html` – Buscador de personas (mínimo 3 caracteres)

## Configuración

En `js/config.js` va la URL del backend y el nombre/grupo del alumno.

## Correr en local

```
npx serve . -l 5500
```
